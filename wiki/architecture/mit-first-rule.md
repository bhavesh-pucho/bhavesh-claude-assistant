# MIT-First Rule

**Summary**: Hard constraint — always prefer MIT-licensed open-source tools before considering alternatives.
**Tags**: #architecture #licensing #mit #policy
**Created**: 2026-04-07
**Last Updated**: 2026-04-07

---

## Rule

Before proposing any new library, tool, or service:

1. Check if an MIT-licensed open-source alternative exists on GitHub
2. Evaluate fit for Pucho AI use case
3. Fork to `PuchoAI-Org` on GitHub if adopting
4. Adapt and integrate — do not build from scratch what already exists
5. Never suggest paid hosted SaaS if a self-hosted MIT option is available

## Corollaries

- Never recommend non-MIT libraries without flagging the license explicitly
- Always PostgreSQL self-hosted — never paid hosted databases
- Never suggest creating accounts on SaaS platforms
